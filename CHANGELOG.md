# Changelog

All notable user-visible changes to the Kanboard TOS application package.

## 1.2.57-1 — 2026-11-15

### Added
- First release. Kanboard (`kanboard/kanboard:v1.2.57`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8173 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/kanboarddocker/`.
